# thomergil/tap

Homebrew casks for [Cannonball](https://github.com/thomergil/cannonball) and
[Open ScanSnap](https://github.com/thomergil/open-scansnap).

```sh
brew tap thomergil/tap
brew trust --cask thomergil/tap/cannonball   # Homebrew asks before loading a cask from a tap
brew install --cask thomergil/tap/cannonball

brew trust --cask thomergil/tap/open-scansnap
brew install --cask thomergil/tap/open-scansnap
```
